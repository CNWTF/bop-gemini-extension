# BOP extension for Gemini CLI

BOP connects Gemini CLI to local service businesses in Taiwan, starting with gyms and personal trainers.

- Search listed businesses by name, city or district, or type of class
- See services, prices, weekly schedules, policies and contact details
- Check open time slots for the next two weeks
- Book, pay for, change or cancel a session

## Install

```bash
gemini extensions install https://github.com/CNWTF/bop-gemini-extension
```

This extension only points Gemini CLI at the hosted BOP MCP server (`https://mcp.srct.tw/mcp`, streamable HTTP). No sign-in is required.
